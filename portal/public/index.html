连接本机 VS Code

按 Microsoft Remote Tunnels 的官方流程连接远端算力。

连接状态尚待确认

先完成扩展安装与远端隧道授权，再从本机编辑器连接。

  1. 01

    在本机安装 Remote - Tunnels

    在 VS Code 扩展中搜索 Microsoft 发布的 Remote - Tunnels，或在本机终端执行下方命令。

    code --install-extension ms-vscode.remote-server
    查看官方扩展
  2. 02

    完成远端隧道授权

    远端隧道启用时，需要登录 GitHub 或 Microsoft 账号。本机 VS Code 请使用同一个账号。

    计划隧道名称wuhan-a800

    当前页面不表示隧道已经启用。先完成远端准备，再进行下一步。

  3. 03

    在本机选择隧道

    按 Ctrl + Shift + P 打开命令面板，运行：

    Remote Tunnels: Connect to Tunnel

    登录与远端相同的账号，选择 wuhan-a800。若名称未出现，请检查远端是否完成授权，以及两端账号是否一致。

  4. 04

    打开远端项目，开始工作

    连接成功后，VS Code 左下角会显示远端主机名称。通过「文件 → 打开文件夹」选择远端项目目录，再使用终端、调试和扩展。
