# 算力工作台 · VS Code 扩展

在桌面版 VS Code 侧栏查看算力资源、传输文件、连接远程 Jupyter。扩展自带本机服务和 Jupyter 离线包，使用 VS Code 内置的运行环境。原算力平台负责账号校验、配额、资源运行和数据存储。

## 安装和登录

1. 在桌面版 Microsoft VS Code 的「扩展」菜单选择「从 VSIX 安装」，选择算力工作台 `.vsix` 文件。
2. 点击活动栏「算力工作台」图标，选择「登录算力平台」。填写平台账号、密码和图片验证码。首次打开侧栏时如图标被收起，也可以在命令面板搜索「算力工作台」。

插件在首次使用时自动启动服务，只监听本机回环地址。扩展和浏览器版分别登录。密码只用于本次登录，会话和模型连接保存在内存中，关闭 VS Code 后需重新登录。

## 使用算力

- **资源**可显示平台实际返回的状态和规格。展开查看详情，右键打开诊断或启动已有资源。启动可能需要等待平台分配资源，实际状态以刷新后的显示为准。
- **文件**从资源的对象存储挂载目录读取，通常是 `/mnt/data`。在资源下选择「浏览和传输文件」，左侧选本机文件，右侧选择目标目录。上传完成后可以复制远端路径在 Notebook 里使用，也可以在右侧下载文件。一次最多上传 20 个文件，总量不超过 5 GB。
- **网页工作区**通过工作台获取短期连接，在独立浏览器窗口中打开。普通网页终端可直接用远端 GPU。
- **桌面远程 VS Code**使用微软官方私有 Remote Tunnels。在运行中的资源下打开「设置桌面隧道」，按下文完成准备和授权。
- **AI 助手**使用你填写的兼容 Chat Completions 的模型服务。在扩展中设置基础 API 地址、模型名和 API Key，再打开聊天。你提交的内容会发给该模型服务。需要模型阅读代码时，可自行把相关片段放入聊天。

## 在本机 Notebook 使用远程 GPU

1. 在算力工作台侧栏登录，启动 A800 并等工作区可打开。Notebook 由微软 Jupyter 扩展提供，VS Code 可通过扩展市场随包安装。自动部署需要本机的 Microsoft Edge 或 Google Chrome。
2. 在 A800 下点击「部署并连接 Jupyter」。工作台检查 `/mnt/data` 中的离线包，缺少时自动上传，随后在当前实例的网页终端安装并验证内核。进度和失败原因会显示在部署页面。
3. 验证成功后，扩展会打开 Notebook 和内核选择器。依次选择「选择其他内核」、「算力工作台 · 远程 Jupyter」和 Python 内核。如果没有打开 Notebook，扩展会创建一个含 `!nvidia-smi -L` 的未保存测试 Notebook。

`.ipynb` 保存在本机，代码在 A800 实例执行。通过工作台上传脚本和数据后，在 Notebook 中使用 `/mnt/data` 下的远程路径。右键选择「断开本机 Jupyter 连接」可以关闭本机转发。实例停止后连接随之中断；新实例需要重新准备。

资源侧栏提供启动、网页工作区和关闭操作。自动停止时间取自平台。选择「用量和费用」可读取平台账单，账单不可见或暂无记录时会显示对应状态。

## 设置桌面隧道

1. 在本机安装微软 Remote - Tunnels 扩展。先启动资源并等网页工作区可用，再在资源下打开「设置桌面隧道」。
2. 在每个新实例首次使用时，点击「准备后台助手」复制命令，再点击「打开网页工作区」，在当前实例的远端终端粘贴并执行一次。看到 `WORKBENCH_HELPER_READY` 后回到面板点击「刷新状态」。平台没有可用于此流程的受支持 Notebook 命令执行接口，这一步由你在远端终端完成。
3. 填写隧道名称，阅读并勾选微软 VS Code 服务器许可，再点「同意并申请设备码」。后端会把当前有效的 GitHub 设备码显示在面板。使用「复制设备码」和「打开 GitHub 设备授权页」，在 GitHub 手动输入并确认授权。
4. 面板显示「隧道已就绪」后，点击「在桌面 VS Code 连接」。如果提示登录，请使用刚才授权的同一个 GitHub 账号。在新窗口确认远程状态后，打开 `/home/work` 或需要的挂载目录，再运行 `nvidia-smi -L` 检查 GPU。隧道就绪与桌面连通是两个状态。

同一实例和助手仍在线时，重新打开面板并刷新即可尝试重连。关闭面板只会停止刷新。需要结束本次授权或隧道时，选择「停止本次隧道」。资源停止后桌面连接会断开。资源重建时，按上述步骤为新实例重新准备和授权。若重启工作台或重新登录后无法读取助手状态，请按面板提示处理当前配对。扩展也保留「连接手动启动的隧道」和网页工作区入口。

本次交付的设备码面板流程和桌面重连仍待用真实 GitHub 账号完成端到端验证。手动连接方式见工作台目录的 `connectors/CONNECTION_GUIDE.zh-CN.md`。微软账号要求和隧道运行方式详见[微软 Remote Tunnels 文档](https://code.visualstudio.com/docs/remote/tunnels)。

## 在算力环境中找到上传的文件

如果上传到 `/mnt/data/项目目录`，请在算力终端或远端文件资源管理器中打开同一路径。工作区通常默认打开 `/home/work`，它是单独的目录。文件列表里的「复制当前远端路径」可以把目标地址复制到剪贴板。

上传对话框和进度通知会显示远端目标目录。传输完成后，等待服务器确认文件数和目标路径。下载时由你选择本机保存位置，完成通知会显示完整路径。目标同名文件已存在时，请换一个名称或位置。传输取消或失败后，文件列表保留当前目录，可选择「刷新当前目录」检查平台实际保存的结果。数据和项目文件请放在平台提供的持久挂载目录。
